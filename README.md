# Arduino 双路巡线小车（PD 版）

Arduino UNO R3 + Keyes L298P 双通道驱动 + 两路红外，用 PD 控制沿黑线跑完一圈：
上电 2 秒后直行进场 → 右转并线 → PD 巡线并数 4 个左弯 → 线尾全白刹车停车。

- **巡线主程序**：`pd_v3.0+1.01.ino`，上电 2 秒自动起步。
- **光敏启动测试**：`pd_light_start.ino`，只保留 A3 光敏电阻的校准、等待和提示，
  不读巡线传感器、不驱动电机。手电一照，D13 快闪 + 串口打印，仅此而已。

本仓库的巡线部分只做巡线。早先的 OpenMV 摄像头／气球识别代码已经删掉了，git 历史里还能翻到。

## 巡线跑起来是什么样（`pd_v3.0+1.01.ino`）

```
上电，电机停住，等 2 秒
        │
        ▼
① 直行进场 ──── 开环直行，忽略出发区边框线
        │        扫到目标边线，或走满 1.5 秒（兜底）
        ▼
② 右转并线 ──── 右轮 0 / 左轮 150，绕右轮划弧
        │        旧线离开探头后，任一路扫到线就算并上；扫不到就一直转
        ▼
③ 上线补偿 ──── 限速 + 修正量打五折 + 固定偏置，骑正立刻结束（最长 300ms）
        │
        ▼
④ PD 巡线 ───── 偏差只有 左(-1) / 中(0) / 右(+1) 三档
        │        ├─ 两路全白 → 丢线找回：按方向记忆划弧，力度随时间加大
        │        ├─ 只左路压线 80ms → 预判左弯：减速 + 轻左带（假弯立刻退出）
        │        └─ 线从左侧消失 → 左弯三拍：弧线切入 → 原地拧 → 边前进边左转
        │                                    数到 1 个左弯，重复到 4 个
        ▼
⑤ 终点 ──────── 第 4 弯后和前面一样巡线，只是挂上“全白即停”的监视：
                 线连续看到 300ms 才算贴稳，之后全白再持续 300ms = 真到线尾
                 → 反脉冲刹车 80ms → 停车
```

五个阶段的分工与参数（代码注释按 `①~⑪` 分区，阶段名和函数名见下）：

| 阶段 | 干什么 | 主要参数 |
| --- | --- | --- |
| ① 直行进场 | 纯开环，只数压过几根线；忽略掉前 1 根后，再扫到线就提前右转 | `START_STRAIGHT_*`、`START_IGNORE_LINES` |
| ② 右转并线 | 绕右轮划弧，闸门逻辑避免“刚起步还没转完就宣布并线成功” | `START_TURN_SPEED`、`START_TURN_INNER_SPEED` |
| ③ 上线补偿 | 刚上线车头是斜的，先限速、PD 打折、按线最后在哪侧带一把 | `MERGE_SETTLE_*`、`MERGE_BIAS` |
| ④ PD 巡线 | 三档偏差 PD；丢线找回；左弯预判 + 三拍 + 真弯计数 | `KP`、`KD`、`BASE_SPEED`、`CORNER_*` |
| ⑤ 终点 | 先“贴稳”才武装终点判据，全白够久才刹停 | `FINISH_*`、`LINE_END_TIMEOUT_MS` |

### 几个设计取舍

- **偏差只有三档**：两路探头给不出“偏了多少”，只有左 / 中 / 右。所以 D 项专门负责状态切换时的阻尼，采样周期必须固定（`SAMPLE_INTERVAL_MS = 5`），不然 Kd 没有意义。
- **左弯三拍，而不是一个劲儿原地转**：第一拍弧线切入不打滑；第二拍内轮倒转让旋转中心移进车体，转得又紧又快；第三拍内轮改回正转，边前进边左扫，把落在圈外的线找回来。内轮在第三拍一旦反转，就变成原地打转，线在圈外转多少圈都扫不到。
- **真弯靠“总白线时长”判**：起转前已经白了多久 + 转弯中白了多久 ≥ 200ms 才算真弯。按“转弯用时”判会漏计真弯，弯数到不了 4，车会一直绕。
- **三个兜底**：内轮反转 + 外轮 210 是电流最大的一拍，前两拍有 500ms（≈90°）硬上限，绝不能原地盲转过半圈；同一个弯最多重转 1 次；总运行 90 秒强制停车。
- **光信号看“跳变”，不只看绝对值**：这条只属于 `pd_light_start.ino`。环境一亮光敏就接近饱和，绝对阈值可能永远够不着；手电是瞬时的，200ms 内的涨幅比绝对值可靠，所以阈值和上升沿两条判据谁满足都算。
- **光敏测试不碰电机**：`pd_light_start.ino` 连 D2/D4/D5/D6 都不初始化，收到信号只闪灯、打印。要跑车就烧 `pd_v3.0+1.01.ino`。

## 光敏测试跑起来是什么样（`pd_light_start.ino`）

```
上电，电机引脚完全不初始化
        │
        ▼
校准 800ms 环境光 ── 得到基线 base、抖动幅度、触发阈值
        │
        ▼
D13 慢闪等待 ────── 手电照 A3 光敏
        │           ① 读数越过阈值，或
        │           ② 最近 200ms 涨幅 ≥ LIGHT_RISE_MIN
        │           再连续保持 80ms 确认
        ▼
D13 三下快闪 + 常亮 ── 串口打印 raw/base/用时
                      程序停在提示状态，电机全程不动
```

## 光敏启动测试（A3）

`pd_light_start.ino` 只验证光敏启动，不驱动电机、不读巡线传感器。

- **怎么算收到**：上电先量 800ms 环境光，得到基线 `base`，阈值 = `base + max(LIGHT_DELTA_MIN, base×20%)`。两条判据满足一条就够——① 读数越过阈值；② 最近 200ms 涨幅 ≥ `LIGHT_RISE_MIN`（传感器接近饱和时绝对值上不去，靠这条）。信号还要连续保持 `LIGHT_STABLE_MS`（80ms）才算数。
- **灯语**：等待时 D13 慢闪；确认收到三下快闪、然后常亮；等满 60 秒没信号快闪 5 下提醒一次，然后接着等。
- **串口**：115200，每 200ms 一行 `raw / base / thr / d / rise`，标阈值就看这个。嫌吵把 `LIGHT_DEBUG_SERIAL` 改 0。
- **只提示不走路**：收到信号后 `setup()` 结束，`loop()` 是空的；D13 常亮，串口打印“测试完成”，电机不会转。
- **手电照不动**：环境太亮时阈值顶到 1000 以上，程序会自动把跳变量减半；还不行就 `TRIGGER_ON_BRIGHT` 改 0 用挡光（变暗）触发，或者给传感器加个遮光筒。
- **测试前断电**：本程序完全不碰电机引脚。车上还接着 L298P 时，请断开电机电源或把四轮架空——驱动板输入悬空可能让轮子抽动。

> 巡线主程序 `pd_v3.0+1.01.ino` **不带**光敏启动，上电 2 秒自动起步。两个程序目前是分开的：一个只测光敏，一个只跑巡线。

## 快速开始

`.ino` 必须先放进同名文件夹（如 `pd_light_start/pd_light_start.ino`），Arduino IDE 才能打开。
`pd_v3.0+1.01` 里的 `+` 不在 IDE 允许字符里，提示 sketch 名不合法时把文件和文件夹一起改成 `pd_v3_1_01` 即可。

**调参阶段一律先架空四轮**：`pd_v3.0+1.01.ino` 上电 2 秒后自动起步；`pd_light_start.ino` 全程不驱动电机，但车上还接着 L298P 时仍建议断开电机电源或架空四轮。

1. **`line_sensor_test.ino`**：串口 9600。探头放白纸上按 `w`、放黑线上按 `b`，程序自动给出结论。把结果填进 `pd_v3.0+1.01.ino` 的 `BLACK_LEVEL`（本车是 `HIGH`）。
   提示语里写的 `car_pd_line.ino` 是旧文件名，现在对应 `pd_v3.0+1.01.ino`。
2. **`motor_test.ino`**：架空四轮，串口 9600。发 `a` 跑完整套，或 `1`~`9` 单项测试。确认每侧两个轮子同向、前进后退方向正确；某个轮子反了就改 `LEFT/RIGHT_MOTOR_INVERT`，或者对调它自己的两根线。
3. **`car_straight.ino`**：找块空地看着它直线跑一段，确认车能走直、方向没接反。
4. **`pd_light_start.ino` 标定光敏**：断开电机电源或架空四轮，串口 **115200**。看每行打印的 `base`，再拿手电照 A3，看 `raw`／`d`／`rise` 涨多少；涨不满 `LIGHT_DELTA_MIN` 就把它调小，或者靠 `LIGHT_RISE_MIN` 走上升沿那条判据。确认 D13 从慢闪变三下快闪并常亮，串口打印“测试完成”。轮子不应该转。
5. **`pd_v3.0+1.01.ino` 巡线**：先按场地量好 `START_STRAIGHT_MS`（让车头到点时正好在边线附近），再用 `BASE_SPEED 100` 左右低速跑整圈，确认能数完 4 个弯、在线尾停住，最后再提到 150。

巡线版停车后 D13 闪几下就是停车原因（闪 N 下 → 停 1.2 秒 → 重复）：

- **1 闪** = 超过 `RUN_SAFETY_TIMEOUT_MS`（90 秒）总时间保护；
- **2 闪** = 走完终点，或任一路连续 5 秒看不到线（`LINE_END_TIMEOUT_MS` 兜底）——2 闪不保证是真终点。

光敏测试版没有停车闪灯：收到信号后 D13 常亮；等待时一直慢闪，每满 60 秒快闪 5 下提醒一次。

## 上车前必须核对的参数

巡线版（`pd_v3.0+1.01.ino`）：

| 参数 | 本车值 | 填错会怎样 |
| --- | --- | --- |
| `BLACK_LEVEL` | `HIGH` | 逻辑整个反过来：白线当黑线、黑线当白线，车完全乱跑 |
| `PROBES_CENTERED_BOTH_ON_LINE` | `1` | 探头间距 12mm < 线宽，骑线时两路都压线。填反则丢线找回、出弯判据、终点判定全乱 |
| `A_CHANNEL_IS_LEFT` | `1` | A 通道（D2/D6）接左侧两轮。填反则左右修正反向，车直接画龙 |
| `LEFT_MOTOR_INVERT` / `RIGHT_MOTOR_INVERT` | `0` | 实际转向和程序相反时改 1 |
| `CORNER_PIVOT_INNER` | `-90` | 负 = 内轮倒转。**要么 0，要么 ≤ -60**：填 -30 落在电机死区，等于没设 |
| `START_STRAIGHT_MS` | `1500` | 直行进场时长。按场地量：到点时车头要正好在边线附近 |

另外 `MIN_SPEED = 60` 是硬死区：任何速度参数绝对值小于 60 都会被 `setMotor()` 当成 0，包括 `START_TURN_INNER_SPEED`、`FINISH_BRAKE_SPEED`、`CORNER_PIVOT_INNER`。

光敏测试版（`pd_light_start.ino`）：

| 参数 | 本车值 | 填错会怎样 |
| --- | --- | --- |
| `TRIGGER_ON_BRIGHT` | `1` | 1 = 手电（变亮）触发。环境太亮、阈值顶到 1000 以上时改 0 用挡光触发；方向填反就永远等不到信号 |
| `LIGHT_DELTA_MIN` | `100` | 触发所需的跳变量，现场标。填太大等不到信号；填太小环境光一抖就自己触发 |
| `LIGHT_STABLE_MS` | `80` | 信号要保持多久才算数。填太小手电扫一下就会抢跑 |
| `LIGHT_RISE_MIN` | `40` | 200ms 窗口内的最小涨幅。环境光接近饱和时主要靠它 |

## 调参对照表

按现象查，一次只改一个参数，改完落地跑一遍。

### 光敏测试（`pd_light_start.ino`）

| 现象 | 先查 / 先改 |
| --- | --- |
| 上电后 D13 一直慢闪，照手电没反应 | 阈值够不着：串口 115200 看 `thr`，手电照上去 `raw` 涨不到它就调小 `LIGHT_DELTA_MIN`，或 `TRIGGER_ON_BRIGHT` 改 0 用挡光 |
| 照了手电，串口 `raw` 纹丝不动 | A3 没接对：确认光敏 S → A3、V/G → 5V/GND；串口有没有 `[light] 校准完成 base=…` |
| 没照手电，程序自己触发 | 环境光抖动或基线漂移：加大 `LIGHT_DELTA_MIN`、`LIGHT_STABLE_MS`，别让阳光直射传感器 |
| 手电扫一下程序就触发 | `LIGHT_STABLE_MS` 加大（80 → 150）；`LIGHT_RISE_MIN` 加大（40 → 80） |
| 串口打印乱码 / 没输出 | 光敏测试是 **115200**，`line_sensor_test`、`motor_test` 是 9600，别混 |

### 巡线（`pd_v3.0+1.01.ino`）

| 现象 | 先查 / 先改 |
| --- | --- |
| 直道上左右画龙 | `KP` 调小（30 → 20）；`KD` 别太大；确认 `SAMPLE_INTERVAL_MS = 5` |
| 直道一摆动就自己减速、往左偏 | `CORNER_PRE_MS` 加大（80 → 120）；还不行 `CORNER_LOST_CONFIRM_MS` 加大（60 → 80/100）；确认 `CORNER_LEFT_HOLD_ENABLE = 0` |
| 弯里冲过头一大段才开始转 | `CORNER_LOST_CONFIRM_MS` 减小（60 → 40）；`CORNER_PRE_MS` 减小；`CORNER_OUTER_SPEED` 稍加 |
| 转完车头没对准就直着冲出去 | `CORNER_PIVOT_INNER` 更负（-90 → -120）；`CORNER_MAX_RETRIES` 保持 1，剩下的偏斜交给丢线找回 |
| 原地拧很久扫不到线 | `CORNER_PIVOT_INNER` 回收到 -60/-70；`CORNER_TIMEOUT_MS` 加大到 600~700，让第三拍有时间扫 |
| 转过头、顺着来时那根线倒回去 | `CORNER_TIMEOUT_MS` 减小（500 → 350~400）；`CORNER_MAX_RETRIES` 千万别大于 1 |
| 弯数到不了 4，车一直绕 | `CORNER_REAL_MIN_MS` 降到 150；再不行先回头确认 `BLACK_LEVEL` 和 `PROBES_CENTERED_BOTH_ON_LINE` |
| 刚出第 4 弯就在弯里刹停 | `FINISH_ARM_MS` 加大（300 → 400） |
| 跑到线尾不停车 | `FINISH_WHITE_MS` 减小（300 → 200）；检查探头离地高度 |
| 跑一半突然停 2 秒又从头来 | 电池弱，大电流拉低电压把 UNO 拉复位了：换电池，或把 `CORNER_PIVOT_INNER` 往回收一点降电流 |
| 轮子嗡嗡响却不转 | 速度低于 `MIN_SPEED` 死区，或者供电不足 |

## 已知限制

- **光敏测试不驱动电机，也不巡线**：`pd_light_start.ino` 只回答“光敏能不能触发”这个问题。
- **巡线版没有光敏启动**：`pd_v3.0+1.01.ino` 上电 2 秒自动起步；要非接触启动，得把 `pd_light_start.ino` 里的 `calibrateAmbient()` / `waitForLightStart()` 搬进巡线版的 `setup()`。
- **直行段开环**：只按 1.5 秒计时 + 数线，地面打滑或电池电压不同就会跑偏，需要靠 `START_STRAIGHT_MS` 现场对。
- **两路探头信息量有限**：只有三档偏差，没法做更细的循迹；也没有编码器闭环。
- **弱电池会装成程序 bug**：电压一掉，UNO 复位，车停两秒再从头跑一遍。
